retraject URDF import — real robots, numeric IK

The industry describes robots in URDF files, and this page loads them. The bundled model is a UR5e built from Universal Robots' published DH parameters — and it demonstrates why the numeric solver exists: the UR wrist has an offset (d₅ ≠ 0), its three wrist axes do not meet in a point, so retraject's analytic spherical-wrist solver refuses the structure — and damped least squares, which needs nothing but forward kinematics and derivatives, takes over. Drag the gizmo: every frame runs DLS. Toggle manipulability to watch the velocity ellipsoid; or import your own file (primitive-geometry URDFs work fully; mesh-based ones need their mesh files hosted alongside).

Part of retraject — the generic Jacobian/DLS machinery this page runs on lives in src/kinematics/ (see its README §6).
